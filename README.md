# Local Vault（PWA配信用）

端末内だけで暗号化して保存する個人用パスワード保管庫の**試作版**です。このリポジトリには、
ブラウザで動かすための静的ファイル（HTML / CSS / JavaScript / manifest / Service Worker / アイコン）だけを置いています。

- 保管庫のデータは利用者の端末（IndexedDB）の中だけに暗号化して保存され、このサイトやGitHubへ送信されません。
- 試作段階で、第三者のセキュリティ監査を受けていません。実在するパスワードの保管には使用しないでください。
- 開発用のソース・テストは別の非公開リポジトリで管理しています。
